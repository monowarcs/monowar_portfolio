## Selected Projects

### Bangladeshi Mango Variety Classifier

**Technologies:** Deep Learning, EfficientNetB0, Streamlit

A deep learning-based system for identifying Bangladeshi mango varieties from images, achieving **98.01% accuracy** and providing real-time prediction through a web-based interface.

### Building Segmentation and Semantic Land-Cover Mapping

**Technologies:** PyTorch, Deep Learning, Semantic Segmentation, Computer Vision

A satellite-image segmentation system for building extraction and semantic land-cover mapping, covering:

* Building
* Open Land
* Paddy Field
* Road
* Vegetation
* Water Body

### Road Scene Object Detection — Improved YOLO

**Technologies:** YOLOv8, Computer Vision, OpenCV, Deep Learning

A multi-class road scene object detection system using an improved YOLO-based architecture, designed for dense and high-occlusion urban traffic scenarios in Dhaka.

### E-Book Subscription Platform

**Technologies:** Django, Python, SQLite, Stripe

A subscription-based eBook platform with Stripe payment integration for accessing and reading books online.

### Wireless Notice Board using GSM

**Technologies:** Arduino IDE, Proteus, GSM

A GSM-based wireless notice board that receives messages through SMS and displays them remotely.

### Smart Dustbin

**Technologies:** Arduino IDE, Proteus, Ultrasonic Sensor, Servo Motor

An Arduino-based smart dustbin that automatically opens its lid when a user is detected nearby.
